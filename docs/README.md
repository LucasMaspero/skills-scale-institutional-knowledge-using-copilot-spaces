# OctoAcme Project Management Docs

This repository contains the core project management processes used by OctoAcme. The documents below provide a practical framework for planning, execution, communication, release, and continuous improvement.

## Project management process summary
OctoAcme follows a simple lifecycle: initiation, planning, execution, release, and retrospective. Teams define goals and stakeholders early, create a prioritized backlog and release plan, manage execution with clear ownership and tracking, communicate risks and blockers openly, and close each milestone with a retrospective and follow-up actions.
